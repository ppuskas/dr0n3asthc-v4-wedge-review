# dr0n3asthc v4 strength wedge

Public visual review of a FLUX.2 Klein base 9B rank-128 LoRA across 17 prompts and
three LoRA strengths (1.0, 1.5, and 2.0). All cells use the same seed, sampler,
steps, CFG, dimensions, base model, encoder, and VAE so strength changes can be
compared directly.

The site is static and dependency-free. Keep/reject decisions are stored only in
the viewer's browser and can be exported as JSON.
